# Imágenes para el Lobby del Quiz - Temática Venezolana

## 📁 Imágenes Requeridas

Coloca estas imágenes en esta carpeta (`assets/images/quiz_lobby/`):

### 1. **sky_gradient.png** (Cielo)
- Tamaño: 1080x2000px
- Degradado de azul claro (#87CEEB) a azul oscuro (#2C5F8D)
- Cielo venezolano despejado

### 2. **avila_mountains_far.png** (Montañas lejanas)
- Tamaño: 1080x600px
- Silueta de montañas del Ávila (verdes oscuras, semi-transparentes)
- Fondo transparente (PNG)
- Color: #6B8E23 con 30% opacidad

### 3. **avila_mountains_near.png** (Montañas cercanas)
- Tamaño: 1080x800px
- Silueta de montañas del Ávila (verdes más oscuras)
- Fondo transparente (PNG)
- Color: #556B2F con 50% opacidad

### 4. **grass_layer.png** (Césped)
- Tamaño: 1080x400px
- Textura de césped verde (#228B22)
- Fondo transparente (PNG)

### 5. **cobblestone_path.png** (Camino de adoquines)
- Tamaño: 200x200px (tile que se repite)
- Textura de adoquines grises/marrones (#8B7D6B)
- Patrón repetible

### 6. **araguaney_tree.png** (Árbol araguaney)
- Tamaño: 150x200px
- Árbol con flores amarillas (#FCDD09)
- Fondo transparente (PNG)

### 7. **yellow_flowers.png** (Flores cayendo)
- Tamaño: 32x32px por flor (sprite sheet de 8 flores)

- Fondo transparente (PNG)

## 🎨 Cómo Generar (Alternativas)

### Opción A: Con IA (Recomendado)
Usa DALL-E, Midjourney o Stable Diffusion con estos prompts:

```
1. "Venezuelan Avila mountain silhouette, dark green, simple vector style, transparent background"
2. "Tropical grass texture, vibrant green, top-down view, seamless pattern"
3. "Cobblestone path texture, gray and brown stones, medieval style, seamless tile"
4. "Araguaney tree with bright yellow flowers, Venezuelan national tree, side view, transparent background"
5. "Small yellow flower petals falling, simple cartoon style, sprite sheet"
```

### Opción B: Con Figma/Photoshop
1. Crea degradados simples para el cielo
2. Usa herramienta de pluma para siluetas de montañas
3. Aplica texturas de grass/stone de recursos gratuitos

### Opción C: Recursos Gratuitos
- **Unsplash**: Busca "caracas avila mountains"
- **Freepik**: Busca "mountain silhouette", "grass texture", "cobblestone"
- **OpenGameArt**: Texturas de juegos

## 🔧 Si NO tienes las imágenes

El juego funcionará de todos modos con:
- Degradado de color sólido (cielo)
- Formas vectoriales generadas en código (montañas, árboles)
- Colores planos
