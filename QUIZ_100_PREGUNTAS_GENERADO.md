## 🎮 SISTEMA INTELIGENTE DE ROTACIÓN

El sistema es **dinámico** y distribuye preguntas según el nivel:

```dart
// Niveles 1-20 → Parte General
// Niveles 21-40 → Delitos Personas
// Niveles 41-60 → Delitos Propiedad
// Niveles 61-80 → COPP
// Niveles 81-100 → Delitos Especiales
// Niveles 101+ → Rota entre todas las categorías
```

**Cada categoría tiene 5 casos base** que rotan internamente, garantizando:
- ✅ Variedad constante
- ✅ Dificultad progresiva
- ✅ Cobertura completa del Derecho Penal Venezolano

### **Ejemplo 2: Delitos Personas - Femicidio**

**Opciones**:
- A) Homicidio simple (Art. 405 CP)
- B) Homicidio calificado (Art. 406 CP)
- **C) Femicidio (Art. 15 LODMVLV)** ✅

### **Ejemplo 3: Delitos Propiedad - Robo Agravado**

**Opciones**:
- A) Hurto calificado (Art. 454 CP)

### **Ejemplo 4: COPP - Flagrancia**
